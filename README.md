# 🏫 효명고등학교 실시간 디지털 방명록

효명고등학교 교직원 및 학생(@hmh.or.kr)들을 위한 따뜻한 실시간 온라인 방명록입니다.

---

## 🌟 프로젝트 특징
- **효명고 전용 인증**: 학교 공식 계정(`@hmh.or.kr`) 소유자만 글을 남길 수 있습니다.
- **실명 기반 소통**: 구글 프로필의 성과 이름이 작성자로 자동 연동되어 책임감 있고 따뜻한 대화가 오갑니다.
- **실시간 데이터 동기화**: 새로고침 없이 다른 사용자가 작성한 글이 화면에 즉시 나타납니다.
- **모던 스쿨 테마**: 모바일 퍼스트 반응형 레이아웃과 감성적인 글래스모피즘 디자인.

---

## 📁 파일 구조
- `index.html`: 메인 방명록 화면 (시맨틱 태그 구조 및 안내 배너)
- `style.css`: 효명고 테마 및 반응형 스타일시트
- `app.js`: 로그인 인증 및 실시간 방명록 제어 로직
- `PRD.md`: 기능 및 기획 요구사항 정의서
- `README.md`: 프로젝트 안내서

---

## 🚀 빠른 시작 가이드 (로컬 테스트)
1. VS Code 또는 안티그래비티 우측 하단의 **[Go Live]** 버튼을 클릭하거나,
2. `index.html` 파일을 우클릭한 후 **'Open with Live Server'**를 선택합니다.
3. 브라우저에서 방명록 화면을 확인하고 메시지를 남겨보세요!
